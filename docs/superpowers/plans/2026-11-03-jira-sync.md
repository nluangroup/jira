## Global Constraints

- Claude moves a card to **Done** only when its implementation PR is merged. Closed-unmerged or open PRs: leave the card, tell the user.
- Done comment, exactly: `PR merged — moved to Done`.
- A card for agreed-but-unplanned work ends its description with `No plan yet`; the plan PR step replaces that with `Plan: <plan path>`.
- Claude never merges or approves a PR.
- `pwsh ./verify.ps1` must pass.

## Review Focus

- No sentence left in `CLAUDE.md` or `README.md` that still says Claude never moves a card to Done.
- The "Find the card" step still creates a card when none exists, so plans without an earlier card keep working.
- The duplicate-card search happens before creating a card for agreed work.
- The Done check names where the PR link is found (the card's final report comment, `PR: <link>`).
- A PR closed without merging never leads to Done.
